# Práctica Auditiva — Dictado de acordes

Aplicación web para practicar el reconocimiento auditivo de acordes.

## Características
La app está pensada para dictar tríadas considerando estado y posición.
Los voicings de los acordes son fijos, en formato de piano y con el bajo octavado.
El audio funciona con samples vía Tone.js
Tiene un contador de aciertos, errores y repeticiones.

## Demo
https://danielms-cl.github.io/dictado-acordes/

## Estructura
- `index.html` — la app
- `piano-sampler.js` — módulo reutilizable de piano
- `samples/` — samples de piano (M36, M52, M65, M78)

App armada con asistencia de DeepSeek.
